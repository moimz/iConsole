# iConsole

AWS · Lightsail, 구글(Cloud · Play) 콘솔, 애플 개발자 계정을 **계정마다 따로 된 로그인**으로 한 창에서 쓰는 macOS 앱.
브라우저 프로필을 오가며 세션이 섞이거나 풀리는 일 없이, 계정을 누르면 그 계정에 열어 둔 탭이 그대로 돌아온다.

## 기능
- **계정마다 독립된 웹 저장소**: 쿠키·로그인이 계정끼리 섞이지 않고, 앱을 껐다 켜도 유지된다.
- **계정 안 탭**: 같은 계정의 탭들은 로그인을 같이 쓴다. 계정을 바꾸면 그 계정의 탭들로 통째로 바뀌고, 다시 켜면 열려 있던 탭을 되살린다(처음 볼 때 읽음).
  - 새 탭: 탭 줄 `+`, ⌘T, 링크 가운데 버튼 · ⌘ 누르고 클릭(뒤에 열기, ⌘⇧ 는 바로 보기), `target=_blank` 링크, 웹뷰 오른쪽 클릭 "새 창에서 링크 열기"
  - 크기를 정해 여는 창(OAuth 팝업)은 따로 된 창으로 연다.
  - 탭 끌어 순서 바꾸기, 가운데 버튼으로 닫기, 오른쪽 클릭: 즐겨찾기 · 주소 복사 · 복제 · 새로고침 · 닫기 · 다른 탭 닫기
- **로그인 자동 채우기**: 저장한 아이디 · 암호 · OTP(TOTP) 를 로그인 페이지에 채운다. 제출(엔터)은 직접 (설정에서 바꿀 수 있음, CAPTCHA 가 보이면 누르지 않음).
  - 아마존: IAM 로그인 화면이면 루트 로그인 링크로 넘어가 이메일 → 암호 → MFA 코드
  - 구글: 이메일 → 암호 → OTP (2단계에서 "Google OTP 앱" 을 고를 때)
  - 애플: 이메일 → 암호. 애플 계정 2단계 코드는 TOTP 가 아니라 채우지 않는다(문자로 받으면 macOS 가 채워 준다).
  - 값은 https 로 열린 그 서비스의 로그인 도메인(`signin.aws.amazon.com`, `accounts.google.com`, `idmsa.apple.com`)에만 넘긴다. 채우기 스크립트는 페이지 스크립트와 떨어진 공간에서 돈다.
- **OTP**: 애플 암호 등에서 꺼낸 `otpauth://totp?secret=…` 줄이나 비밀 값을 넣으면 앱이 코드를 만든다.
- **즐겨찾기**: 탭 오른쪽 클릭 · 주소칸 ☆ · ⌘D. 사이드바 계정 꺾쇠를 펼치면 보이고, 누르면 그 계정의 같은 주소 탭(없으면 새 탭)으로.
- **그룹**: 사이드바 `+` → 그룹 추가. 계정을 끌어 그룹을 옮기거나 순서를 바꾸고, 그룹 머리를 끌어 그룹 순서를 바꾼다.

## 단축키
| 키 | 동작 |
|---|---|
| ⌘T / ⌘⇧T | 새 탭 / 닫은 탭 다시 열기 |
| ⌘W / ⌘⇧W | 탭 닫기 / 창 닫기 |
| ⌘L | 주소칸 |
| ⌘R | 새로고침 |
| ⌘[ / ⌘] | 뒤로 / 앞으로 |
| ⌃Tab · ⌘⇧] / ⌃⇧Tab · ⌘⇧[ | 다음 탭 / 이전 탭 |
| ⌘D | 즐겨찾기 추가 · 빼기 |
| ⌘+ / ⌘- / ⌘0 | 확대 / 축소 / 실제 크기 |
| ⌘⇧N | 계정 추가 |

## 데이터 위치
| 무엇 | 어디 |
|---|---|
| 계정 목록 · 즐겨찾기 | `~/Library/Application Support/iConsole/accounts.json` |
| 그룹 | `~/Library/Application Support/iConsole/groups.json` |
| 암호 · OTP | 이 맥 로그인 키체인 (서비스 `com.moimz.iConsole`) |
| 계정별 로그인(웹 데이터) | WebKit 저장소 (계정 UUID) |
| 열린 탭 · 마지막 계정 | 앱 설정(UserDefaults) |

## 아직 안 되는 것
- iCloud 동기화 (맥끼리 계정 · 키체인 공유)
- 앱 안 웹뷰에서 패스키 · 애플 암호 자동 완성 (macOS 가 브라우저 권한 없는 앱에 막는다)
- AWS 액세스 키로 콘솔 바로 들어가기(페더레이션), App Store Connect API 화면

## 빌드
macOS 26, Xcode 27. 외부 라이브러리 없음.
