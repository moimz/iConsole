# iConsole

AWS · Lightsail, 구글(Cloud · Play) 콘솔, 애플 개발자, Cloudflare 계정(그리고 직접 정한 사이트)을 **계정마다 따로 된 로그인**으로 한 창에서 쓰는 macOS 앱.

여러 개의 루트 계정 · 개발자 계정을 브라우저 하나로 관리하면 프로필을 바꿀 때마다 세션이 섞이고, 로그인이 자꾸 풀리고, 어느 브라우저 어느 프로필에 로그인해 뒀는지 헷갈린다.
iConsole 은 계정마다 독립된 웹 저장소와 탭 묶음을 두고, 로그인 페이지에서는 저장해 둔 아이디 · 암호 · OTP 를 채워 준다. 사이드바에서 계정을 누르면 그 계정에 열어 둔 탭이 그대로 돌아온다.

## 설치
- [Releases](https://github.com/moimz/iConsole/releases/latest) 에서 `iConsole-<버전>.dmg` 를 받아 Applications 로 끌어 놓는다.
- macOS 26 이상, 애플 실리콘(arm64) 전용. 애플 공증(notarize)을 받은 앱이다.
- 새 버전은 앱이 하루에 한 번 확인해 설치할지 묻는다 (iConsole > 업데이트 확인…, 설정 > 일반 > 업데이트).

## 시작하기
1. 사이드바 `+` → **계정 추가**: 종류(아마존 · 구글 · 애플 · Cloudflare · 사용자 정의), 이름, 아이디, 암호, OTP(선택), 시작 주소(선택), 그룹.
2. 계정을 누르면 그 계정의 콘솔이 열린다. 로그인 페이지에서는 아이디 · 암호 · OTP 가 채워지니 엔터만 누른다.
3. 한 번 로그인하면 앱을 껐다 켜도 그 계정의 로그인과 탭이 남아 있다.

## 기능
- **계정마다 독립된 웹 저장소**: 쿠키·로그인이 계정끼리 섞이지 않고, 앱을 껐다 켜도 유지된다. 애플 개발자 사이트처럼 로그인을 "세션 쿠키"로 주는 곳도 앱을 끄면 풀리지 않게 30일 쿠키로 바꿔 남긴다(서버가 정한 만료는 어쩔 수 없다).
- **계정 안 탭**: 같은 계정의 탭들은 로그인을 같이 쓴다. 계정을 바꾸면 그 계정의 탭들로 통째로 바뀌고, 다시 켜면 열려 있던 탭을 되살린다(처음 볼 때 읽음). 열린 탭은 맥마다 따로다(동기화하지 않음). 탭에는 사이트가 주는 제목과 사이트 아이콘(파비콘)이 보인다.
  - 새 탭: 제목줄 오른쪽 끝 `+`, ⌘T, 링크 가운데 버튼 · ⌘ 누르고 클릭(뒤에 열기, ⌘⇧ 는 바로 보기), `target=_blank` 링크, 웹뷰 오른쪽 클릭 "새 창에서 링크 열기"
  - 크기를 정해 여는 창(OAuth 팝업)은 따로 된 창으로 연다.
  - 탭 끌어 순서 바꾸기, 가운데 버튼으로 닫기, 오른쪽 클릭: 즐겨찾기 · 주소 복사 · 복제 · 새로고침 · 닫기 · 다른 탭 닫기
- **로그인 자동 채우기**: 저장한 아이디 · 암호 · OTP(TOTP) 를 로그인 페이지에 채운다. 제출(엔터)은 직접 (설정에서 바꿀 수 있음, CAPTCHA 가 보이면 누르지 않음).
  - 아마존: IAM 로그인 화면이면 루트 로그인 링크로 넘어가 이메일 → 암호 → MFA 코드
  - 구글: 이메일 → 암호 → OTP (2단계에서 "Google OTP 앱" 을 고를 때)
  - 애플: 이메일 → 암호. 애플 계정 2단계 코드는 TOTP 가 아니라 채우지 않는다(문자로 받으면 macOS 가 채워 준다).
  - Cloudflare: 이메일 → 암호 → 2단계 코드
  - **사용자 정의**: 메인 페이지 · 로그인 페이지 주소와, 아이디 · 암호 · 2단계 코드 칸 이름(name · id 또는 CSS 선택자, 비우면 자동으로 찾기)을 직접 정한다. 로그인 페이지(없으면 메인 페이지) 도메인에서만 채운다.
  - 2단계 화면(주소에 totp · mfa · 2fa · two-factor 등)이면 이름을 몰라도 보이는 빈 칸 하나를 코드 칸으로 본다.
  - 값은 https 로 열린 그 서비스의 로그인 도메인(`signin.aws.amazon.com`, `accounts.google.com`, `idmsa.apple.com`)에만 넘긴다. 채우기 스크립트는 페이지 스크립트와 떨어진 공간에서 돈다.
- **OTP**: 애플 암호 등에서 꺼낸 `otpauth://totp?secret=…` 줄이나 비밀 값을 넣으면 앱이 코드를 만든다. 계정 편집 창의 코드(남은 시간 동그라미 + `137 530`)를 누르면 클립보드로, 계정 오른쪽 클릭 "OTP 코드 복사" 도 있다. 편집 창에서 OTP 비밀 값을 눈 버튼으로 보고, `otpauth` 주소 복사 · QR 로 다른 인증 앱에 옮길 수 있다. 계정 ID(고유 값)도 보인다.
- **제목줄**: [‹ ›] · 가운데 넓은 주소칸 [☆ 주소 ↻] (Safari 처럼 새로고침이 주소칸 안) · 오른쪽 끝 [+]
- **페이지 번역**: 주소칸의 번역 버튼 · ⌥⌘T. 애플 번역(Translation)으로 이 맥 안에서 번역해 페이지 글자가 밖으로 나가지 않는다. 다시 누르면 원문, 화면이 계속 바뀌는 페이지도 새 글자를 이어서 번역, 코드 · 입력칸은 그대로. 번역할 언어는 설정 > 일반 > 번역.
- **즐겨찾기 막대**: 탭 줄 위(Safari 즐겨찾기 막대처럼), 지금 계정의 즐겨찾기만. 탭 오른쪽 클릭 · 주소칸 ☆ · ⌘D 로 추가(사이트 제목 · 주소를 채운 시트에서 고친 뒤 추가, 이미 있으면 편집 · 빼기). 누르면 지금 탭에서, ⌘ 누르고 누르거나 가운데 버튼이면 새 탭. 끌어 순서 바꾸기, 오른쪽 클릭으로 편집 · 빼기.
- **사이드바 계정 줄**: [서비스 아이콘(대표색 + 흰 로고)] 이름 / 아이디, 이번에 열어 본 계정은 오른쪽에 열린 탭 수(초록 알약).
- **사이드바 검색**: 위 검색칸(⌥⌘F), 띄어 쓴 낱말이 이름 · 아이디 · 그룹 · 서비스 · 시작 주소에 모두 들어 있는 계정만.
- **그룹**: 사이드바 `+` → 그룹 추가. 계정을 끌어 그룹을 옮기거나 순서를 바꾸고, 그룹 머리를 끌어 그룹 순서를 바꾼다.
- **MCP** (설정 > MCP): Claude Code 같은 AI 도구가 계정별로 로그인된 탭을 열고, 페이지를 읽고, 누르고 입력하게 하는 로컬 서버 (`http://127.0.0.1:8768/mcp`).
  - 도구: `list_accounts` · `list_tabs` · `open_tab` · `select_tab` · `read_page`(페이지 글자 + 누를 수 있는 것 · 입력칸에 [번호]) · `screenshot` · `click` · `fill` · `select_option` · `wait`
  - 접근 범위: 지금 보고 있는 계정만 / 고른 계정만 / 모든 계정
  - 권한: 읽기 전용 / 확인 후 실행(누르기 · 입력마다 허용 · 거부 창) / 모두 허용
  - 암호 · OTP 는 어떤 도구로도 넘기지 않는다. 로그인 페이지는 읽기 · 입력 모두 막고, 암호 칸 값은 읽지도 쓰지도 않는다. 단, 로그인 뒤 콘솔 페이지에 보이는 값(예: OAuth 클라이언트 보안 비밀)은 읽힐 수 있다.
  - Claude Code 연결: 설정 > MCP > "연결 명령 복사" (`claude mcp add --transport http iconsole http://127.0.0.1:8768/mcp`)

## 단축키
| 키 | 동작 |
|---|---|
| ⌘T / ⌘⇧T | 새 탭 / 닫은 탭 다시 열기 |
| ⌘W / ⌘⇧W | 탭 닫기 / 창 닫기 |
| ⌘L | 주소칸 |
| ⌘R | 새로고침 |
| ⌥⌘T | 이 페이지 번역 / 원문 보기 |
| ⌘[ / ⌘] | 뒤로 / 앞으로 |
| ⌃Tab · ⌘⇧] / ⌃⇧Tab · ⌘⇧[ | 다음 탭 / 이전 탭 |
| ⌘D | 즐겨찾기 추가 · 편집 |
| ⌘+ / ⌘- / ⌘0 | 확대 / 축소 / 실제 크기 |
| ⌘⇧N | 계정 추가 |
| ⌥⌘F | 사이드바 검색 |
| ⌘, | 설정 [일반(웹 페이지 모드 · 로그인 채우기 · 웹) · MCP] |

## 데이터 위치
| 무엇 | 어디 |
|---|---|
| 계정 · 즐겨찾기 | iCloud Drive 앱 전용 폴더 `iCloud.com.moimz.iConsole/Data/Accounts/<UUID>.json` (계정마다 하나, 맥끼리 동기화) |
| 그룹 | 같은 폴더 `Data/groups.json` |
| 암호 · OTP | iCloud 키체인 동기화 항목 (서비스 `com.moimz.iConsole`, 접근 그룹 `XSDBV8D2XL.com.moimz.iConsole`) |
| 계정별 로그인(웹 데이터) | WebKit 저장소 (계정 UUID, 맥마다 따로) |
| 열린 탭 · 마지막 계정 | 앱 설정(UserDefaults, 맥마다 따로) |
| 사이트 아이콘 | iCloud Drive 같은 폴더 `Data/Favicons/` (그림은 아이콘 주소별 png, 페이지 → 아이콘 짝 `pages.json`, 맥끼리 동기화) |

iCloud Drive 나 iCloud 키체인을 못 쓰면 이 맥(`~/Library/Application Support/iConsole`, 로그인 키체인)에 두고 사이드바 아래에 "이 맥에만 저장" 이 뜬다.

## 아직 안 되는 것
- 앱 안 웹뷰에서 패스키 · 애플 암호 자동 완성 (macOS 가 브라우저 권한 없는 앱에 막는다)
- AWS 액세스 키로 콘솔 바로 들어가기(페더레이션), App Store Connect API 화면

## 보안 · 개인정보
- 암호 · OTP 비밀 값은 키체인에만 두고, 계정 파일 · 로그 · MCP 어디로도 내보내지 않는다.
- 로그인 칸 채우기는 그 서비스의 https 로그인 도메인에서만 한다.
- 페이지 번역은 맥 안에서(애플 Translation) 하고, 사이트 아이콘 말고는 앱이 따로 외부로 보내는 것이 없다.
- MCP 서버는 이 맥(127.0.0.1)에서만 받고 기본은 꺼져 있다.

## 빌드
